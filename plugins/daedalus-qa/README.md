# daedalus-qa

Browser QA companion for the `daedalus` workflow. It adds the `daedalus-qa:qa-tester` role, the `manual-qa` skill and
`/daedalus-qa:manual-test`, which open the pages a change touched in Chrome through the Playwright MCP server and check every
acceptance criterion with screenshot evidence. It needs Node.js 18+ and Chrome. Install it only for projects with a UI,
since the Playwright server starts whenever the plugin is enabled.

## Install

```
/plugin install daedalus-qa --marketplace iamjcabalejo/daedalus
```
