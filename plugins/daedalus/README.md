# daedalus

A plug-and-play Plan → Code → Review → QA workflow for Claude Code. At session start it detects the project's stacks,
commands and integrations into `.workflow/profile.json`; `/daedalus:setup` confirms them. `/daedalus:feature-plan` writes a
plan with one task block per layer, and `/daedalus:project-manager` runs `daedalus:implementer` per layer, then
`daedalus:test-runner`, then an Argus review. Load the `daedalus:workflow-contract` skill for the rules.

## Install

```
/plugin install daedalus --marketplace tb-jcabalejo/tb-claude-custom-workflow
```

Projects with a UI also install the browser-QA companion: `/plugin install daedalus-qa --marketplace tb-jcabalejo/tb-claude-custom-workflow`.

Generated by `scripts/build-plugin.sh` from the repository's `.claude/` tree; don't edit it here.
